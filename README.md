# ⏱️ DevTimeTracker

📖 **Read this in other languages:**
- [English](README.en.md)
- [Русский](README.ru.md)

---

**DevTimeTracker** — умный и лёгкий трекер времени для разработчиков. Автоматически отслеживает, сколько времени вы проводите в PyCharm, VS Code, IntelliJ IDEA и других редакторах кода. Работает в фоне на Linux, Windows и macOS.
